# Explodables Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Explodables** by Martin Green (Fearitude).

- Original: https://stealthwareastro.pages.dev/articles/explodables
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.30.0+

This port contains **no original assets**. Put your own copy of the original jar (`Explodables-1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
